# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.6.x | yes |
| older than 1.6 | no |

1.6.0 is the current release.
Only that release line gets security fixes.

## Reporting a vulnerability

Report a vulnerability in private.
Use GitHub private vulnerability reporting.
Do not open a public GitHub issue for a security report.
Do not put the details in a pull request.

Open a report here:

<https://github.com/davidteren/mutineer/security/advisories/new>

If that page does not accept a report, enable private vulnerability reporting
in the repository security settings.
Then use the same page.
