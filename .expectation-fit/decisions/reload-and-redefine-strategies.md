# Reload and redefine strategies

- **Model ActiveSupport Prepended Hooks.** When reviewing `prepended` handling in the concern stub, preserve ActiveSupport's behavior: store the first block, raise `MultiplePrependBlocks` for a second block, and run the hook only on the first prepend. (cubic `e5066b28`)
- **Reload Concern Placement Boundary.** When documenting Mutineer `--strategy reload` for a mutated method from an ActiveSupport concern's `included` or `prepended` block, describe the placement as limited to a *placeable* method, state that hosts include or prepend the concern, and preserve the `unplaceable` result (`no_coverage` for a `:maybe` selection) for methods reload cannot place. Do not imply reload runs every hook-block mutant in a concern file containing an `included` or `prepended` block; such mutants that reload cannot place are `unplaceable` when their tests were selected as `:run`, and stay `no_coverage` when selected as `:maybe`. Not when: Do not say `--strategy reload` runs these mutants for a concern file with an `included` or `prepended` block under ActiveSupport. (cubic `b6084bd3`, updated 2026-11-16)
- **Safe Fallback for Mutated Blocks.** When reload replacement blocks have different compiled bodies, pair leftovers by place without code only when the old and new counts are equal; keep all copies when a same-place concern makes the counts differ. (cubic `76d6306d`)
- **Compare Callback Conditions.** In `ReloadGuards::RepeatedCallbacks.same?`, include ActiveSupport callback `if:` and `unless:` conditions when matching entries so callbacks with the same filter but different conditions remain distinct. (cubic `f365f80c`)
- **Normalize Optional Callback Kind.** When reviewing `skip_callback` argument handling, treat the kind as optional: if the first argument is not `:before`, `:after`, or `:around`, use `:before` and treat that argument as a filter, matching Rails normalization. (cubic `c893c69a`)
- **Dynamic Dispatch in Hook Self-Use.** In `placeable_hook`, treat `send`, `public_send`, and `__send__` like `method` and `instance_method`: count literal symbol or string names as self-use, and mark the whole hook block unplaceable when a name is computed at runtime. (cubic `4bb04fa6`)
- **Redefine Enclosing-Method Limits.** When documenting the `redefine` strategy for nested methods, state that it reloads directly enclosing methods and advise `--strategy reload` for methods nested in blocks such as `define_method`. (cubic `913fb352`)
- **Use Byte Offsets for ReachProbe.** When calculating source offsets passed to `ReachProbe.wrap` alongside byte lengths, use `byteindex` so the offsets and lengths share byte units. (cubic `71aa1755`)
- **Reset ReachProbe sentinel state.** When clearing a ReachProbe sentinel after load, also reset its process-local guard so a load-time run does not suppress recording a later test-phase run. (cubic `0a350852`)
- **Document Thread.current[] as Fiber-Local.** When documenting state stored with Ruby's `Thread.current[]`, describe it as fiber-local and clarify that it is not one value for the whole thread. (cubic `e6de3a59`)
- **Conditional Bootsnap Cache Setting.** For apps that call `Bootsnap.setup` directly, recommend setting `compile_cache_iseq` to `ENV["DISABLE_BOOTSNAP_COMPILE_CACHE"].nil?` so the cache is disabled only when that variable is set. Not when: Do not apply this rule to apps that do not call `Bootsnap.setup` themselves; the conditional guidance is for direct callers. (cubic `fd02fb46`)
- **Keep the Live Superclass on Reload.** When the reload text reopens a class whose superclass is a call (`Data.define`, `Struct.new`, `Class.new`), wrap the superclass in `ReloadGuards.kept_superclass` so the class reopens as the same object; a method inside the superclass call's block is `unplaceable` under reload. For a plain local write (`class Q < (base = Struct.new(:a))`), wrap only the written value, so the local is still set (#512). Not when: the superclass is a constant or a bare variable read, also in parentheses, or sets a local in another way (#527). (#492)
- **Keep a Superclass Constant on Reload.** When a class statement inherits from a constant that the same file assigns, wrap the value in `ReloadGuards.kept_constant`, so the class reopens with the same parent; `Project.kept_constant_write?` decides which writes, for discovery and the reload text alike. (#503)
- **Keep Only a Literal Class Builder.** Keep a constant's value only when it is `Struct.new`, `Data.define` or `Class.new` with literal arguments (`Project.kept_builder?`); leave any other value as written, so the file errors visibly instead of keeping a class its mutant never reaches. Not when: never widen this to a builder method of the file or an argument that reads a constant (#533). (#503)
- **Match a Kept Constant by Spelling.** A bare write matches a bare superclass (`< X` or `< ::X`) in any scope; a path write matches only a path superclass spelled the same, and its parent must be absent (`::X = ...`), a constant path or `self`. Not when: the write is `||=` (#529) or no class statement in the file names it (#528). (#503)
- **Mark Every Def in a Kept Value.** A def inside a kept constant value is `unplaceable` under reload (`Subject#in_kept_constant`), counted in `summary.unplaceable`; discovery uses the same `kept_constant_write?` as the rewrite, so it never misses a kept value. (#503)
- **Callback Growth Warning Is Report-Only.** When reviewing the reload callback-growth warning, keep it to one header line that counts each class once, and one line for each class and file whose own count grew, and keep verdicts, the score and the exit code unchanged; the JSON report only lists the same rows in `summary.callback_growth` (#505). Not when: a class only inherited its parent's growth. (#479)
- **Keep a Defined Callback Chain on Reload.** During a mutant load, `ReloadGuards::CallbackRedefinition` drops a `define_callbacks` name whose chain the class itself defined before the load (the class owns `_run_<name>_callbacks`), so concern and subclass callbacks stay and the class body's repeats pair through `RepeatedCallbacks`. Not when: the name is new to the class, or the call is outside a load; `reset_callbacks` is #530. (#504)
- **Mark a Def That Calls define_callbacks.** The reload skip drops the call's options, so discovery marks a def that calls `define_callbacks` or `define_model_callbacks` (any receiver) anywhere in its body, including inside a nested def or block, and a def of the file that calls such a def by name or through `super`, `Subject#calls_define_callbacks`: `unplaceable` under reload only. Not when: the def only computes the names or options, the call goes through `send`, `public_send`, `__send__` or `method`, or the caller is in another file (#530). (#504)
