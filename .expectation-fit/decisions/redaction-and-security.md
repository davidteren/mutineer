# Redaction and security

- **Document ASCII Word Boundary.** When documenting whole-word redaction governed by `WORD_CHAR`, specify that the boundary uses ASCII letters, digits, and underscores. (cubic `c55ae168`)
- **Short-form password redaction boundaries.** In `Mutineer::Redaction`, forms of three characters or fewer, and forms made only of ASCII word characters at any length, use whole-token matching; longer forms with a non-word character use substring redaction. Apply the length threshold (three characters or fewer) independently to each raw, decoded, or escaped password form, not to the decoded password as a whole, and require ASCII token boundaries at both ends, including when either form edge is punctuation. A longer password form or a longer encoded form (for example a percent-encoded string) that holds a non-word character still uses substring matching and must not be treated as a short form. (cubic `a4129068`, `43743c3a`, updated 2026-11-16)
- **Password Query Value Boundaries.** When reviewing `password=` query-value redaction, verify that `.`, `?`, `!`, and `;` terminate the value while longer values such as `admin` remain intact. (cubic `2c58ba70`)
- **Name Supported Dotenv Files.** When reviewing `docs/json-schema.md` for `DATABASE_URL` redaction coverage from dotenv files, name the six supported files: `.env`, `.env.local`, `.env.development`, `.env.development.local`, `.env.test`, and `.env.test.local`. (cubic `8dcc6740`)
- **Read Every Dotenv Line.** When parsing a dotenv file in `DatabaseUrls.from_file`, read every line without truncating at a byte limit so a later `DATABASE_URL` is registered for redaction. (cubic `441d58e7`)
- **Clear Runner-Owned Redaction URLs.** When Runner loads dotenv URLs into `Redaction.extra_urls`, clear that list during cleanup regardless of filter ownership; preserve a list set by the CLI for CLI restoration. Not when: Do not clear the list when the CLI set it itself; leave it for the CLI to restore. (cubic `5eb8d01a`)
- **Require Started Filter Before Boot.** When reviewing daemon boot handling of `OutputFilter.install`, allow boot to continue only for `:started`; treat `:failed` as a boot error that exits through the boot rescue. (cubic `897d0378`)
- **Silence Output When Child Copier Fails.** When `OutputFilter` starts in a fork child, verify that stdout and stderr are silenced if the child copier does not return `:started`, preventing child-only credentials from reaching the parent pipe. (cubic `d8bed3e3`)
- **Buffer Newline-Spanning Passwords.** When OutputFilter encounters a password form spanning newlines, preserve the bytes until the complete form is available, then redact the form as one secret. (cubic `41962858`)
- **Exec URL With Unset Environment.** When reviewing `exec` handling, if `unsetenv_others: true` is set, determine the child's `DATABASE_URL` from the supplied environment hash only; do not fall back to the current process's `ENV`. (cubic `bf3e7cf4`)
- **Fail Closed for Unknown Spawn URLs.** When OutputFilter handles spawn or system with an environment hash setting an unknown DATABASE_URL, suppress stdout and stderr, replacing any caller redirect of those streams; keep ENV-known URLs on the redaction path. Not when: Do not apply this rule to backticks, IO.popen, or shell commands that set DATABASE_URL themselves; those paths are not covered by the described hooks. (cubic `2ec521e4`, updated 2026-11-16)
- **Wrap Kernel Singleton Hooks.** When adding fork or exec hooks for `Kernel.exec` or `Kernel.fork`, also prepend the corresponding hook to `Kernel.singleton_class` because these are singleton-method entry points. (cubic `1b291023`)
- **Parse URL Labels Independently.** When parsing URL labels, derive the host from the authority and the database name from the path independently of userinfo, including URLs without `@` credentials. (cubic `2f62d423`)
- **Redact MySQL Version Output.** When `check_mysql_server` prints a server version in a warning or refusal, verify it is redacted with `Redaction.text` and that the configured password is also hidden. (cubic `d3d5f49f`)
- **Daemon Stderr Redaction Limits.** When reviewing Mutineer daemon-stderr redaction claims, qualify them to note that bare passwords loaded only by the app after boot may pass through, while URL credential redaction still applies. (cubic `46f109de`)
- **Buffer Daemon Stderr by Line.** For the daemon stderr drain, keep partial lines buffered until newline or EOF before redacting and forwarding them; do not forward arbitrary read chunks that could split supported credentials. Not when: Do not apply this rule to stderr output that is not handled by this daemon drain or when a separately established redaction method safely handles credentials split across arbitrary reads. (cubic `87668e42`)
- **Preserve Fork Rescue Errors.** When the forked clean-pass rescue handles an exception, verify that its result payload preserves the redacted exception description rather than an empty report. (cubic `2433fb60`)
- **Reject Traversal in Test Map Patterns.** When validating `tests:` map patterns in `parse_test_map_patterns`, reject any pattern containing a `..` path segment with `ConfigError` so it cannot traverse outside the run directory. (cubic `694caae4`)
- **Keep Split-Test Search In Root.** Reject a split-test search directory in `split_tests_in` when its expanded path lies outside the project root. (cubic `b5a241d1`)
