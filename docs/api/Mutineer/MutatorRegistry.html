Overview

Maps operator names to operator classes.

DEFAULT_NAMES is the v1 default set (Tier-1 plus statement-removal). The Tier-2 operators live in ALL but are OFF by default — they only run when named via --operators or operators: in .mutineer.yml. Keeping DEFAULT_NAMES an explicit subset (not ALL.keys) is what keeps the default survivor set unchanged.
