Overview

Operand-removal mutator (Tier-2).

Replaces a boolean expression with one of its operands, two mutations per &&, ||, and or or: a && b becomes (a) and (b). The parentheses keep the precedence of and and or. A surviving mutant shows that no test needs the operand that was removed.

def emit(node)
  [[node.left, node.right], [node.right, node.left]].each do |kept, removed|
    next if JUMPS.any? { |type| kept.is_a?(type) } || heredoc?(removed)

    @mutations << Mutation.new(
      start_offset: node.location.start_offset,
      end_offset: node.location.end_offset,
      replacement: "(#{kept.slice})",
      operator: :operand_removal
    )
  end
end
