Overview

Safe-navigation mutator (Tier-2).

Replaces &. with ., one mutation per occurrence. The mutant raises NoMethodError on a nil receiver, so it survives when no test passes nil.

def emit(node)
  return unless node.safe_navigation?

  loc = node.call_operator_loc
  @mutations << Mutation.new(
    start_offset: loc.start_offset,
    end_offset: loc.end_offset,
    replacement: ".",
    operator: :safe_navigation
  )
end
