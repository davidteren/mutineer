Overview

Aggregates a flat list of Results into counts, the mutation score, and the surviving-mutant list. The score denominator is killed + survived ONLY: no-coverage, uncapturable, skipped (invalid), errored, timeout, and ignored (equivalent-mutant suppression) are each excluded and surfaced separately, so suppressing every survivor reaches 100%. An empty denominator yields a nil score (rendered "N/A"), never 0.0, distinguishing "no testable mutants" from "0% killed".

def by_source
  @results.select { |r| r.subject }
          .group_by { |r| r.subject.file }
          .transform_values { |rs| AggregateResult.new(rs) }
end

def mutation_score
  return nil if covered_count.zero?

  (killed_count.to_f / covered_count * 100).round(1)
end
