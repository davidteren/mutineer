Overview

No require_relative "runner" on purpose: runner.rb requires this file, and the reverse edge makes Ruby warn "circular require considered harmful" on every -w load. Runner is loaded first on every real path; requiring this file alone leaves it undefined. Rationale and the real fix: #75.
